# 宇树和其他品牌的夹爪、灵巧手

网页：https://tony1213.github.io/robot-hands-3d/

## 对模型做了什么

- 网格做过简化：宇树的六款按 0.3–0.7 mm 的格子合并顶点；其他厂家的先在 0.02 mm 的格子上焊接顶点，再用边折叠简化，形状误差不超过 0.2 mm。坐标存成 16 位整数，法向存成 8 位整数。
- 每个网格文件（`unitree_ends_mesh/`、`other_hands_mesh/`）开头写着它取自哪个仓库的哪次提交、做过什么改动，以及原许可证的全文（没有许可证的写明没有）。
- 连杆、关节原点、轴和限位照原模型。颜色、立柱、「合拢」姿态是这里加的，不是厂家给的。

## 这个仓库

除了 `source/` 里厂家的原文件，文件都由另一个项目里的脚本生成，不在这里手改。GitHub Pages 直接发布 `main` 分支的根目录。
